# Текстуры бумаги

`paper-left.webp` используется на левой странице, `paper-right.webp` — на правой. Приложение загружает оба файла из этой папки.

Каждая текстура заполняет свою половину разворота с сохранением пропорций. Излишки изображения обрезаются от центра. Пока файла нет, соответствующая страница использует базовый цвет бумаги.
